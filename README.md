# 复古照片时间水印工具

批量给照片打上复古风格时间戳，留住拍摄瞬间，多年后回看依然记得当时的时光。

一个轻量前端工具，上传照片，批量添加时间水印，本地浏览器运行，不上传图片到服务器。

区别于相机 APP 只能拍照时加水印、工具只能单张处理的局限，这个工具支持批量上传照片，快速添加时间水印。

- 时间读取优先级：文件名日期 > EXIF 拍摄时间 > 文件系统时间
- 如果识别时间不准确，可以直接修改照片文件名来自定义时间
- 全程在浏览器本地运算，图片不会上传到任何服务器，保护隐私

- 开发方式：Claude 辅助生成代码，独立完成需求定义、交互设计、体验调优
- 技术：纯 HTML，无后端，开箱即用
- 在线演示：https://sienna2026.github.io/watermark/
